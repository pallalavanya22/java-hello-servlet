# Java Hello Servlet

My first Java Web Application built while learning Java Servlets.

This project is a simple **Hello World** application that demonstrates how a Java Servlet works with a JSP-based web application.

## 🚀 Project Overview

The application displays a simple Hello World page and provides a link to access a Java Servlet.

When the user clicks **"Hello Servlet"**, the request is handled by the Servlet and a response is returned to the browser.

## ✨ Features

- Hello World web page
- Simple JSP page
- Java Servlet example
- Servlet request and response handling
- Basic web application structure
- Runs on Apache Tomcat
